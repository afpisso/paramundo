# Originales de arte de cartas

Aquí van las imágenes tal como salen de ChatGPT, una por carta, con cualquier nombre. Claude reconoce
cada criatura, la renombra como `<id>.png` (por ejemplo `chigui.png`) y la procesa. Los prompts están en
`docs/art/prompts-chatgpt.md`.

El juego no carga nada de esta carpeta: Claude procesa estos originales y deja el resultado en
`public/art/cards/`.
