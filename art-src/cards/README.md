# Originales de arte de cartas

Aquí van las imágenes tal como salen de ChatGPT, una por carta, con el nombre `<id>.png` (por ejemplo
`chigui.png`). Los prompts y los ids están en `docs/art/prompts-chatgpt.md`.

El juego no carga nada de esta carpeta: Claude procesa estos originales y deja el resultado en
`public/art/cards/`.
